# Customer Behavior Analysis

## Overview

This project focuses on analyzing customer behavior and sales trends using Data Analytics techniques. The workflow includes data loading, data cleaning, SQL-based analysis, visualization, and dashboard creation to generate meaningful business insights.

The project demonstrates practical skills in Python, MySQL, and Power BI for data preprocessing, analysis, and reporting.


## Dataset

The dataset contains customer transaction and sales-related information such as:

* Customer demographics
* Purchase history
* Product categories
* Sales and revenue details
* Customer behavior patterns


## Tools & Technologies Used

* Python
* Pandas
* NumPy
* MySQL
* Power BI
* Jupyter Notebook
* Microsoft Excel


## Project Workflow

### 1. Data Loading

* Imported dataset into Python using Pandas
* Inspected dataset structure and data types

### 2. Data Cleaning & Preprocessing

* Handled missing values
* Removed duplicate records
* Renamed and formatted columns
* Standardized data formats
* Created derived features for analysis

### 3. SQL Analysis

* Imported cleaned data into MySQL
* Executed SQL queries for:

  * Customer segmentation
  * Revenue analysis
  * Sales trends
  * Product performance
  * Customer purchase behavior

### 4. Exploratory Data Analysis (EDA)

* Analyzed customer trends and purchasing patterns
* Identified high-performing products and categories
* Evaluated customer engagement and revenue distribution

### 5. Power BI Dashboard

Created an interactive dashboard to visualize:

* Sales performance
* Customer insights
* Revenue trends
* Product category analysis
* Key business metrics

### 6. Report Generation

Prepared a detailed analytics report summarizing:

* Key findings
* Business insights
* Data-driven conclusions


## Key Results

* Identified customer purchasing trends
* Analyzed revenue growth patterns
* Discovered high-performing product categories
* Generated business insights through visual analytics
* Built an interactive dashboard for decision-making support
